# CoreScan 工业体数据检查

CoreScan是本地工业CT切片探索工作台。输入图像体数据以Z/Y/X顺序保存；体素间距和原点以毫米表示，原点是首体素中心。它用于检查、测量和演示，不用于医疗诊断或工业安全认证。

启动：`python3 -m pip install -r requirements.txt`，随后`./start.sh`。访问 http://localhost:18925 。`CORESCAN_DATA_DIR`指定持久化目录，`PORT`覆盖监听端口。Docker Compose使用独立的corescan-data卷。

点击“载入合成铸件”得到两个48×80×88的合成工业零件扫描。素材是确定性模拟，不是真实采集。选择体数据后可以查看Z、Y、X正交切片并调整显示窗；显示窗不会改变数据值。勾选参与运算的体，选择操作、核对参数并运行。结果保存输入快照、参数、数值报告、体数据和支持图，点击“查看并选中结果体”继续处理。

支持正交最大/最小/均值/积分投影、物理坐标裁剪、物理半径平滑、梯度、强度直方图、逐层统计、体素重采样、同网格比较、三维直线剖面、阈值分区、二值形态整理、三维连通对象测量、标签提取、无效区域排除和局部统计。所有派生体保留输入来源，间距/原点修改另存副本。结果ZIP含报告、CSV和NPY；项目ZIP含当前文档和所有内容寻址对象。检查快照记录体列表与结果ID。刷新页面重新打开已有项目。

NPY须为有限单通道三维数值数组；NPZ包含volume，可附spacing和origin；ZIP包含至少两张同尺寸灰度PNG/TIFF，按文件名数字自然排序，可带metadata.json。单次上传不超过96MB，最多800万体素，每轴2–1024。压缩包不写入服务器文件树。NPZ导出同时包含valid支持数组和完整元信息，重新导入会保留；NPY/切片ZIP没有提供支持信息时视为全有效。导入表单的元信息覆盖字段默认空对象，沿用文件本身信息。

二值形态操作要求binary单位，标签提取要求labels单位；这两个类型只允许最近邻重采样。体积来自体素计数乘实际体素体积，表面积是轴对齐体素面面积，非平滑曲面估计。边界或无效支持相邻的连通对象单独标记不完整。正交积分只累加有效体素，不是缺失数据的估计。线性重采样保留首体素中心，末采样不超过原数据范围。

核心后台在corescan包。image_lab提供可实际访问的二维图像准备台（/prepare）：图像导入、曝光/颜色处理、配准、融合、掩膜、质量分析及图像输出，用于检查切片来源和准备二维输入。它与三维检查使用分开的持久化子目录；三维处理不隐式调用二维配准。

## 从原始平行束投影重建（/recon）

`/recon` 是平行束透射投影重建工作台，与直接导入NPY/NPZ/ZIP体数据的原流程并存、互不影响。输入一个ZIP（`projections/` 放灰度投影，行对应相同轴向位置；`dark/`、`flat/` 各放至少一张同尺寸暗场、空场）和角度表CSV（列：文件名,角度(度)，按文件名配对）。角度允许不等间隔、重复或缺失；容量与体数据一致（单包96MB，探测器每边4–320，视图最多240）。

工作流分三态，全程在乐观锁版本下固化：
1. **核对（curating）**：逐张查看原始投影与暗空场校正后的线积分，手工修正角度配对、整图剔除坏投影、指定独立留出投影。校正把饱和坏点、低于透射率下限的计数、截断边界列和整图剔除只写入有效射线掩码，绝不按零吸收参与运算；每视图给出有效射线率、饱和计数等统计。
2. **双方案证据（reconstructed）**：一次同时给出直接恢复（斜坡滤波FBP，按角度中点权重归一化）和带非负、平滑约束的逐步拟合（FISTA最小二乘，只拟合有效射线）。留出投影不参与任一方案，仅用于独立核对。页面并排列出两方案在训练集与独立留出投影上的RMSE/MAE、逐视图残差、体切片与方案差异图，以及可靠/未决/不可恢复三级支持图（按角覆盖、最大角间隔、视场截断半径和逐体素有效射线比例评定）。更低拟合误差或更平滑不自动代表更可信，需结合小孔薄壁条纹、边缘损失和留出一致性人工裁决；约束在未决区补出的结构不标为已证实。
3. **确认（confirmed）**：选择方案并记录裁决理由后生成带毫米间距与原点（首体素中心）的三维体，仅把可靠支持标为有效。确认后原始投影、暗空场、角度配对、剔除与留出集合、几何设置、两方案证据和确认结果全部冻结；改角度或试别的设置请克隆会话，已确认体不会被改写。确认体进入 `/` 三维检查页，可沿Z/Y/X查看、窗调、物理坐标裁剪、分区与测量，原直接导入流程照常可用。

往返核验：任一方案的恢复体都可按原始角度、旋转方向和视图顺序重新投影，残差只在同样的有效射线上计算，缺失支持和剔除视图保持掩码角色，不被当作测到零吸收；逐视图残差表区分训练、留出与剔除。会话证据可单独下载ZIP（含全部NPY数组与逐视图CSV），项目导出ZIP包含会话引用的所有内容寻址对象，重开后证据链完整。

几何参数（探测器像素间距du、轴向间距dz、旋转中心列索引、旋转方向±1、重建网格边长与体素间距、截断边界列数、饱和阈值、透射率下限、FISTA平滑权重与迭代数）在确认前可改，改动会自动重算暗空场校正；重建/确认后设置冻结。重建为CPU实现，迭代预算（迭代≤60、网格≤320、总体素≤800万）内仍须按本机内存选择尺寸。

## 运行环境

CPU实现，无GPU依赖。体素预算限制内仍须根据本机内存选择尺寸。较多连通碎片可能昂贵，连通对象数量最多50000；物理球结构元素限制25万元素。网页结果表格直接显示全部记录，实际交互性能取决于记录数。Python 3.11/3.12依赖在requirements.txt按解释器锁定。
